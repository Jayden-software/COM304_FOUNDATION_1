# Council Proposal 6

## Explanation of this proposal
*What do you think this proposal might mean? How might it be implemented?*

Within this designated proposal the idea is to make the council's web site and a council App the primary gateways for the public to engage with the council's services. What this may mean is that the council wants to make all the primary access online instead of in person meeting or phone calls, moreover, the council must write code for an app including having a web developer, this will ensure that the process of application will be adequate. Furthermore, this can be implemented through first creating an app for the council, secondly the council must choose a gateway path such as a default path which is the ordinary path or having a parallel path in which is where the you have multiple pathways that can amalgamate simultaneously.
